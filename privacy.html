Privacy Policy

Effective date: 17 September 2026

Marble Bloom is designed for children and deliberately limits remote data to technical reliability, performance and debugging information.

Information Marble Bloom uses

Marble Bloom uses device motion while the game is open so that tilting the iPhone or iPad can move the on-screen marbles. During ordinary play, raw tilt readings are not sent as part of the always-on technical telemetry.

The game stores the player’s current level locally on the device so play can continue later. This local progress is not tied to an account or online profile.

Technical telemetry

Marble Bloom sends a small amount of technical telemetry to our own diagnostics server so we can identify crashes, regressions and performance problems. This can include the app version/build and platform, app start/stop events, startup and frame-performance measurements, limited coded game events, coded errors, and privacy-scrubbed software stack traces when JavaScript errors occur.

Each app run uses a new random technical session identifier. Marble Bloom does not create or send a persistent user or device identifier for this system. Raw telemetry is kept for a limited period, currently up to 30 days, before automatic deletion.

Optional high-rate diagnostics

A hidden troubleshooting mode can be deliberately enabled during testing. While it is enabled, Marble Bloom can send higher-rate tilt and game-physics measurements such as tilt direction and magnitude, frame timing and marble speed. This stream stops when the diagnostic mode is turned off.

Personal information

Marble Bloom does not require an account and does not ask for a child’s name, email address, location, contacts, photos, microphone, camera or advertising identifier. The technical telemetry contract rejects common identity, location, advertising and free-text fields. Server access logging is disabled so client IP addresses are not retained as telemetry access logs.

Analytics and advertising

Marble Bloom does not use third-party behavioural analytics or advertising in the current release-candidate configuration. Technical observability is self-hosted and is used for reliability, performance and debugging rather than personal profiling. If a future public version enables advertising, this policy will be updated before that version is released.

Sharing and sale of data

Marble Bloom does not sell personal data. Technical telemetry is not provided to advertisers. Infrastructure providers may process network traffic as needed to deliver the service.

Changes

This policy will be updated if the app’s data practices materially change. The effective date above will be updated at the same time.
