Privacy Policy

Effective date: 16 September 2026

Marble Bloom is designed for children and is built to minimise data collection.

Information Marble Bloom uses

Marble Bloom uses device motion data while the game is open so that tilting the iPhone or iPad can move the on-screen marbles. The game does not store or transmit that motion data.

The game stores the player’s current level locally on the device so play can continue later. This local progress is not tied to an account or online profile.

Personal information

The current version does not require an account and does not ask for a child’s name, email address, location, contacts, photos, microphone, camera or other personal information.

Analytics and advertising

The current release-candidate configuration does not enable third-party analytics or advertising. If a future public version enables advertising, it will use child-appropriate contextual advertising only, and this policy will be updated before that version is released.

Sharing and sale of data

Marble Bloom does not sell personal data. The current version does not share child personal information with third parties.

Changes

This policy will be updated if the app’s data practices materially change. The effective date above will be updated at the same time.

For support, please use the Marble Bloom support page.
